# Go Tutorial

A small Go learning project that prints `Hello, World!` to the terminal.

## Files

- `main.go`: The entry point of the program.

## How to Run

Run the program with:

```bash
go run main.go
```

Expected output:

```text
Hello, World!
```

## What This Example Shows

This project introduces the basic structure of a Go executable program:

- `package main` tells Go that this package should build as an executable program.
- `import "fmt"` brings in Go's formatting package so the program can print text.
- `func main()` is the starting point where the program begins running.

## Next Steps

You can continue learning by changing the printed message, adding variables, or creating more functions.
